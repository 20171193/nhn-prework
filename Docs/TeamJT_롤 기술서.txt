## 담당 역할
전투 시스템 개발 — PvP 동기화, 공격/피격 처리, 증강이 적용될 수치 변수화

## 실제 구현한 영역
- **네트워크 동기화**: Photon PUN2 기반 1:1 매칭/방 구성, 이동·조준·발사 RPC 동기화, 발사체는 로컬 재생 + 맞은 사람 본인이 판정하는 victim-authoritative 구조로 설계
- **전투 코어**: 부채꼴 발사, 무기/투척무기 사거리 표시 시스템, 발사체 오브젝트 풀링
- **투척무기 시스템**: 조준 → 포물선 궤적 미리보기 → 투척 → 판정/이펙트 전체 파이프라인, 슬롯(3개) 관리
- **수치 구조화**: 무기/발사체/투척무기를 `Database<T>` 제네릭 기반 ID 조회 구조로 통일, 증강이 적용될 수치를 base값 + StatModifier 목록으로 분리해 증강 시스템이 직접 손대지 않고 얹을 수 있게 설계
- **UI/카메라**: 커스텀 커서 상태 시스템, 로비 플레이어 세팅(이름/무기 선택) UI, Cinemachine 카메라 추적
- **씬 관리**: 멀티/싱글플레이 씬 분리, 공용 페이드인/아웃 전환 시스템
- **사운드**: BGM/SFX/AMB 재생 시스템 설계 및 전투 이벤트 연동

## 협업 방식
- `develop` 브랜치를 기준으로 팀원과 지속적으로 pull/merge 진행, Unity 씬 파일 충돌은 UnityYAMLMerge로 안전하게 해결
- 증강 개발자와 접점 코드(StatModifier 인터페이스, ThrowableWeaponController 등) 설계를 사전 협의해 각자 영역에서 독립적으로 확장 가능하도록 구성
- 커밋 메시지에 변경 유형(prefix)과 다음 작업 계획을 함께 남겨 팀원이 진행 상황을 추적할 수 있게 관리

- 안태홍 (이탈)
## 담당 역할
증강 시스템 개발 — 증강 데이터/획득/적용 구조, 매치 진행 흐름(GameFlow), 매치메이킹

## 실제 구현한 영역
- **증강 시스템**: 증강 데이터를 `AugmentData` 기반으로 유형별(`StatAugmentData`/`SkillAugmentData`/`ThrowableAugmentData`) 분리 설계, `AugmentCatalog`/`AugmentManager`/`AugmentPool`로 증강 풀 관리·랜덤 제시·리롤 기능 구현
- **증강 선택 UI**: 증강 선택 화면(`AugmentSelectionUI`), 카드 UI(`AugmentCardUI`, 호버 차단 포함), 로프 형태 타이머 UI(`RopeTimerUI`) 구현, 상대 선택 대기 표시 추가
- **매치 진행 흐름(GameFlow)**: 매치 전체 단계(준비 → 전투 → 증강 선택 반복 → 종료)를 관장하는 `GameManager` 설계, 클라이언트 간 진행 상태를 맞추는 `GameFlowSync` 구현, 게임 종료 후 로비 복귀 흐름 및 결과/타이머 UI(`MatchResultUI`/`MatchStartUI`/`MatchTimerUI`) 구현
- **매치메이킹**: 1:1 매치메이킹 프로토타입(`MatchmakingManager`/`MatchmakingUI`) 구현
- **HUD 연동**: 플레이어 HUD(`PlayerHUD`), 증강 획득 아이콘 표시(`AugmentButton`) 구현 및 UI 렌더 소팅 이슈 처리
- **공용 유틸/에디터 도구**: 싱글턴 베이스(`Singleton`), 이벤트 버스(`EventBus`), 코루틴 대기 캐시(`YieldCache`) 등 공용 유틸 작성, 증강 데이터용 커스텀 인스펙터(`AugmentCatalogEditor`, `StatAugmentSetup`) 제작
- **아트/폰트 리소스 통합**: 한글 지원 폰트 적용, 로비/증강 UI 아트 리소스 임포트 및 반영

## 협업 방식
- `feature/augments` 브랜치에서 개발 후 `develop`에 병합, 전투 시스템(심재천) 쪽과 접점 코드(`PlayerCombatContext`, `ThrowableWeaponController`, `StatModifier` 등)를 공유하며 진행
- 게임 진행 흐름의 주인(마스터 클라이언트)을 명확히 나누는 구조로 설계해 네트워크 동기화 담당과 역할 경계를 분리

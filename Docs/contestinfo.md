## 1. 대회 개요
- **명칭**: NAN 2026 — NHN Game × AI 해커톤
- **주최**: NHN
- **컨셉**: "AI를 활용하는 사람은 많다. 우리가 찾는 사람은 AI의 다음 단계를 설계할 디렉터다"
- **진행 방식**: 본행사 시작과 동시에 주제 공개 → 이후 48시간 개발. 서류·사전 과제 심사를 거쳐 총 10팀 선발
- **참가 자격**: 만 19세 이상 누구나, 팀당 최대 3인
- **상금 + 채용 혜택**: 총 3.5억 원 규모 (팀 상금 + 채용 관련 혜택 합산)

## 4. 사전 과제: "AI를 활용한 게임 제작"
제출 필수 항목 5개, **하나라도 누락 시 심사 제외**.

1. **플레이 가능한 빌드 + 전체 소스코드**
   - 웹(GitHub Pages 링크로 브라우저 바로 실행) 또는 모바일 앱(APK·테스트 링크) 중 하나 이상
   - 심사자가 직접 플레이 가능해야 함
   - PC 실행파일(.exe) 제출 불가
   - 저장소는 공개 권장, 비공개 시 심사 계정(dl_gameai_reviewer@nhn.com) 초대 필요
   - 커밋 기록 유지 필요
2. **플레이 동영상**
   - 30~60초, 실제 플레이 화면만 사용 (AI 합성·타 영상 도용 금지)
   - 유튜브 공개 또는 일부 공개로 업로드
3. **게임 소개 및 설명 문서 (PDF)**
   - 제목/한 줄 소개, 플레이 방법(목표·조작·종료 조건), 실행 방법, 플레이 링크, 플레이 영상 링크
4. **AI 활용 기술 문서 (PDF)**
   - 사용한 AI 도구·프롬프트·활용 내역
   - 외부 에셋/오픈소스 출처 명시
5. **팀원 롤 기술서 (PDF)** — 2인 이상 팀만 해당
   - 팀원별 이름·역할·담당 영역·협업 방식

## 5. 유의사항
- 타인 저작물 무단 도용 시 선발 취소 가능

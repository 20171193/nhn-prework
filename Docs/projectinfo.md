## 1. 제출 항목 진행 체크리스트
(상세 제출 요건은 contestinfo.md 4번 항목 참고)
- [ ] 플레이 가능한 빌드 + 전체 소스코드 (웹 GitHub Pages 또는 APK)
- [ ] 플레이 동영상 (30~60초)
- [ ] 게임 소개 및 설명 문서 PDF
- [ ] AI 활용 기술 문서 PDF
- [ ] 팀원 롤 기술서 PDF

## 2. 게임 한 줄 소개
증강 선택(뱀파이어 서바이벌 류) + 1:1 실시간 PvP. Unity 웹 빌드 기준, APK도 고려. 레퍼런스: 브롤스타즈. 비주얼은 브롤스타즈/아이작 느낌의 단순하고 귀여운 2D 캐릭터, 전투는 대조적으로 잔인한 느낌을 살림.

## 3. 확정된 핵심 규칙

### 3-1. 매치 구조
증강 선택 → 전투(1라운드) → 증강 선택 → 전투(2라운드) → 증강 선택 → 전투(3라운드)
**3라운드는 무조건 전부 진행한다.** 중간에 크게 앞서도 조기 종료 없음.

### 3-2. 점수 제도 (v1 — 추후 개편 예정)
- 라운드 승리 = 1점, 패배 = 0점
- 3라운드 누적 점수가 많은 쪽이 최종 승리
- 라운드 시간 초과 시, 그 시점 잔여 체력이 많은 쪽이 해당 라운드 승리 처리
- ⚠️ 구현 단순화를 위한 v1이며, 추후 데미지/체력 비율 기반 등으로 개편 가능성 있음. 점수 계산 로직은 별도 함수/모듈로 분리해서 나중에 교체하기 쉽게 구현할 것.

### 3-3. 증강 시스템 원칙
- 라운드 패배해도 획득한 증강 효과는 사라지지 않고 계속 누적
- 증강 예시: 발사체 개수 증가(부채꼴), 발사체 벽 튕김(1회), 발사체 속성 부여, 수류탄/연막탄/섬광탄 스킬 획득 등
- [ ] 확인 필요: 증강 목록 중 "발사체 개수 증가" 중복 기재 — 별개 증강인지 확인

### 3-4. 무기 시스템 범위
- 이번 사전 과제 범위에서는 **1종류로 고정 제공**
- 무기 선택 시스템(활/저격총 등)은 **본행사 확장 후보로 보류**, 이번 스코프 제외

### 3-5. 전투 조작 방식 — 테스트 중 (결과 나오면 이 섹션 업데이트)
1안: 수동 이동만 (자동 조준, 자동 발사)
2안: 수동 이동 + 수동 조준 (자동 발사)
3안: 수동 이동 + 수동 조준 + 수동 발사
→ 8/1~8/2 팀 테스트로 확정 예정 (기준: 러닝커브, 전략적 깊이, 웹 빌드 반응성, 모바일 확장성)

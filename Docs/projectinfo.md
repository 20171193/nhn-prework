## 1. 제출 항목 진행 체크리스트
(상세 제출 요건은 contestinfo.md 4번 항목 참고)
- [ ] 플레이 가능한 빌드 + 전체 소스코드 (웹 GitHub Pages 또는 APK)
- [ ] 플레이 동영상 (30~60초)
- [ ] 게임 소개 및 설명 문서 PDF
- [ ] AI 활용 기술 문서 PDF
- [ ] 팀원 롤 기술서 PDF

## 2. 게임 한 줄 소개
증강 선택(뱀파이어 서바이벌 류) + 1:1 실시간 PvP. Unity 웹 빌드 기준, APK도 고려. 레퍼런스: 브롤스타즈. 비주얼은 브롤스타즈/아이작 느낌의 단순하고 귀여운 2D 캐릭터, 전투는 대조적으로 잔인한 느낌을 살림.

## 3. 확정된 핵심 규칙

### 3-1. 매치 구조 (최종 확정 — 2026-08-10)
3분 30초 단일 매치. 라운드제가 아니라 하나의 연속된 전투 안에서 0초/1분/2분 시점에 스킬(증강) 획득 기회가 주어진다.
> ⚠️ 이전에 여기 적혀있던 "증강선택→전투(1R)→...→3R" 3라운드 구조는 폐기됨. 아래 팀원 롤 기술서/게임소개 문서가 최종 기준.

### 3-2. 승패 판정
- 상대방이 사망하면 승리, 자신이 사망하면 패배
- 제한시간(3분 30초) 종료 시 아무도 사망하지 않았다면 무승부

### 3-3. 증강(스킬) 시스템 원칙
- 단일 매치 안에서 0초/1분/2분 시점에 획득한 증강 효과는 매치가 끝날 때까지 계속 누적
- 증강 예시: 발사체 개수 증가(부채꼴), 발사체 벽 튕김(1회), 발사체 속성 부여, 수류탄/연막탄/섬광탄 스킬 획득 등

### 3-4. 무기 시스템 범위
- 이번 사전 과제 범위에서는 **1종류로 고정 제공**
- 무기 선택 시스템(활/저격총 등)은 **본행사 확장 후보로 보류**, 이번 스코프 제외

### 3-5. 전투 조작 방식 (최종 확정)
**완전 수동 — 수동 이동 + 수동 조준 + 수동 발사.** 자동 발사는 폴백 옵션 토글로만 유지.
